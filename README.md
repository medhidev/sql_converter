## Présentation

La mission principale de ce projet est d'offrir une interface simple et intuitive, la plus synthétique possible, tout en facilitant la conversion des données métier au format .csv, .xls, .xlsx.
Ce projet permettrait donc aux techniciens de simplifier la traduction de données métier vers un format de traitement.
À titre informatif, le site web ne stocke en aucun cas, de façon persistante, ces informations, pour des raisons de conformité au RGPD, mais aussi parce que ce traitement n'est pas nécessaire.

## Setup du projet

```bash
# Téléchargement avec git du projet en local
$ git clone https://github.com/medhidev/sql_converter

# Aller dans le dossier racine du projet
$ cd sql_converter

# Lancement de la page en local
$ ./index.html

```
