## Présentation

Ce projet a pour objectif de simplifier la traduction des données de type tableur au format .csv, .xls, .xlsx pour les convertir en requête SQL.
Ce projet permettrai aux techniciens de simplifier la traduction de données métiers vers un format de traitement.
Cette traduction ne stoque en aucun cas de façon persistante les informations pour des raisons de conformité.

La mission principale de ce projet et d'offrir une interface simple et intuitive la plus synthétique possible. Ce besoin étant important lors de la traduction des données.

## Fonctionnalités

* Prise en charge du format csv
* Drag & drop d'un fichier tableur
* Affichage des données SQL sur le site
* Téléchargement du fichier au format sql
